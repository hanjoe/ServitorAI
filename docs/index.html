SERVITOR AI

Warhammer × Catppuccin quick-chat for macOS
View on GitHub

WHAT IT IS

A keyboard-first, borderless AI chat panel that lives in your menu bar. No Electron, no web UI — just Swift, AppKit, and a warm pi --mode rpc process in the background.

INSTALL

git clone https://github.com/hanjoe/ServitorAI.git cd ServitorAI ./install.sh

DEFAULT SHORTCUTS

ShortcutAction
⌘⇧AShow / hide the panel
↵Submit question
⌃CCopy last answer
⌃⇧1 … ⌃⇧0Copy or open the numbered target in view
⌃RRegenerate
⌃NNew chat
⌃[ / ⌃]Older / newer chat
⌃,Edit keybinds.conf

CONFIGURATION

Put your provider key in ~/.config/servitorai/config.json. Edit ~/.config/servitorai/keybinds.conf with ⌘, — the app reloads keybindings on save, no restart needed.
